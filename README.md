📋 نبذة عن النظام

نظام إلكتروني متكامل لإدارة ومتابعة الشكاوى في مركز القلب والقسطرة القلبية، يتيح للمرضى والموظفين تقديم الشكاوى ومتابعتها إلكترونياً، مع نظام صلاحيات متكامل، وإحصائيات تفاعلية، وتقارير قابلة للتصدير — كل ذلك دون الحاجة إلى خادم، فالنظام يعمل بالكامل داخل المتصفح.

> ⚕️ الهدف: تعزيز الشفافية وتحسين جودة الخدمات الصحية من خلال قناة رسمية ومنظمة لاستقبال شكاوى المرضى وملاحظاتهم ومعالجتها في الوقت المناسب.

🚀 التشغيل السريع

الطريقة الأولى: التشغيل المباشر
1. حمّل المشروع كملف ZIP
2. فك الضغط عن الملف
3. افتح `index.html` في المتصفح — لا يحتاج النظام إلى أي خادم أو تثبيت


# الدخول إلى مجلد المشروع
cd heart-center-complaints-system

# فتح النظام في المتصفح
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

الطريقة الثالثة: خادم محلي (اختياري)

```bash
# باستخدام Python
python -m http.server 8000

# باستخدام Node.js
npx serve .
```

ثم افتح: `http://localhost:8000`

📖 دليل الاستخدام المختصر

1. تسجيل الدخول بأحد الحسابات الافتراضية أو حساب جديد.
2. تقديم شكوى من صفحة «شكوى جديدة» مع تحديد الأولوية وإرفاق الملفات إن لزم.
3. المتابعة من صفحة «شكاويّ» لمعرفة الحالة: قيد المراجعة ← قيد المعالجة ← تم الحل.
4. الرد والمعالجة (للطبيب/المدير) من لوحة إدارة الشكاوى.
5. التقارير من لوحة الإحصائيات مع إمكانية التصدير بأي صيغة.
